# Legacy profile format

applyd now uses structured `profile.json`, not a prose `profile.md`, as its
authoritative candidate profile. This file remains only to prevent older links
from silently leading users to the wrong setup.

Start with [`profile.example.json`](profile.example.json) and complete
[`PROFILE_QUESTIONS.md`](PROFILE_QUESTIONS.md). The full process is documented
in [`setup.md`](setup.md#4-build-profilejson).
